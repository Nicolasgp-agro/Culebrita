# Culebrita

La culebrita clásica como app web instalable (PWA): pantalla completa, ícono propio y juego sin internet.

**Instalar en Android (Chrome):** abre el enlace de la app → menú ⋮ → *Instalar app* / *Agregar a pantalla principal*.
**Instalar en iPhone (Safari):** abre el enlace → botón Compartir → *Agregar a inicio*.

Controles: botones o deslizar el dedo en el celular; flechas/WASD y Espacio en el computador.
